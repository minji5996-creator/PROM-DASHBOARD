## 집계 원칙

- 주간 운영 목표 10,000회는 유지합니다. 동일 기간의 일별 발생 자료가 없어 이번 주 실적/달성률은 확인 필요로 표시합니다.
- 1/7/30일 필터는 해당 길이로 실제 수집된 자료만 표시합니다. 7일은 YouTube 원본 10.15~10.21이며 기준일에서 역산한 7일이 아닙니다. 전체 관측은 각 채널의 원본 기간을 표시합니다.
- 게시 후 누적 수치는 기간 발생량으로 바꾸거나 날짜별로 배분하지 않습니다.
- 전환은 저장·공유·리포스트·클릭의 합입니다. 구성항목이 일부만 수집됐으면 확인된 합계와 `일부`를 표시합니다. 누락은 0이 아닙니다.
- 팔로워 합계 29,632는 수집된 4개 채널 보유 수의 합이며 사람 중복 제거 및 Facebook 포함 합계가 아닙니다.
- YouTube 최신 영상은 인벤토리 8회, 실시간 분석 9회의 보고 시차가 있습니다. 콘텐츠 표는 인벤토리 누적 범위를 사용합니다.
- YouTube 실제 영상 ID가 있는 항목만 원본 썸네일 URL을 사용합니다. 다른 채널의 미수집 이미지를 임시 이미지로 대체하지 않습니다.
- 원본 CSV는 `data/`에서 다운로드할 수 있습니다. `data.js`에는 정규화된 관측 자료와 출처를 보존합니다.

## 실행 및 검증

```sh
python -m http.server 8000
node --check app.js
node verify.cjs
```

브라우저에서 http://localhost:8000 을 엽니다. GitHub Pages는 `main` 브랜치의 저장소 루트(`/`)를 자동 배포합니다.

목표와 변경 이력은 브라우저 localStorage에 저장됩니다. 이전 데모 저장 키는 제거합니다. 실제 주간 성과가 부족하면 자동 목표 추천을 표시하지 않습니다. 월요일 09:00 한국시간 알림은 Codex 채팅의 별도 자동화이며 저장소만 배포해도 새로 생성되지는 않습니다.

`import_data.py`는 원본 ZIP에서 데이터를 재생성하는 도구입니다. 원본 ZIP 경로는 실행 환경에 맞게 지정합니다. 첨부 파일의 설명문은 관측 자료로만 취급하며 실행 지시로 사용하지 않습니다.
