# SOCIAL PULSE · SNS KPI Dashboard

Instagram, Facebook, YouTube, X, 기타 채널의 성과를 모아 보는 한국어 SNS KPI 대시보드입니다.

GitHub Pages: https://minji5996-creator.github.io/PROM-DASHBOARD/

## 주요 기능

- 주간 합산 조회수 목표 및 달성률, 목표 수정과 브라우저 저장
- 최근 최대 4개 완료 주 평균 × 110%를 100회 단위 올림한 목표 추천
- 1일 / 7일 / 30일 / 전체 기간 필터
- 채널별 팔로워, 유효 게시글, 조회수, 전환수, 댓글
- 조회수 추이와 채널 기여도
- 이미지 썸네일을 포함한 콘텐츠 검색, 채널 필터, 성과 정렬
- 전체 / 채널 / 콘텐츠 / 업데이트 기록 CSV 내보내기
- 별도 업데이트 기록 화면

## 실행

빌드나 패키지 설치가 필요 없는 정적 HTML/CSS/JavaScript 프로젝트입니다.

```sh
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. 저장소 루트(`/`)를 정적 호스팅의 배포 디렉터리로 지정합니다. GitHub Pages는 `main` 브랜치의 루트를 자동 배포합니다.

## 검증

Node.js가 설치된 환경에서 실행합니다.

```sh
node --check app.js
node verify.cjs
```

검증 스크립트는 집계, 중복 제거, 기간 필터, CSV 생성 호출, 목표 수정을 확인합니다. 실제 브라우저 화면 검수를 대신하지 않습니다.

## 데이터와 저장 범위

- 모든 성과는 데모 데이터입니다. 실제 SNS API와 연결되지 않았습니다.
- 샘플 데이터 기준일은 2026-10-23입니다. 해당 주 샘플 조회수는 8,420회, 기본 목표 10,000회 대비 84.2%입니다.
- 주간 KPI는 한국시간 월요일~일요일, 기간별 분석은 샘플 기준일을 사용합니다.
- 팔로워는 기준일 보유 수입니다. 채널 간 동일 사용자를 제거한 수치가 아닙니다.
- 게시글은 채널과 게시물 ID 기준으로 중복 제거합니다.
- 전환수는 저장 + 리포스트·공유 + 링크 클릭입니다.
- 목표와 변경 이력은 브라우저 localStorage에 저장되며 다른 기기와 동기화되지 않습니다.
- 매주 월요일 09:00 한국시간 알림은 Codex 채팅에 별도로 설정되어 있습니다. 이 저장소만 배포하면 알림이 자동 생성되지는 않습니다.
- 콘텐츠 사진은 주제 구분용 샘플이며 실제 게시물 썸네일이 아닙니다. 출처: [ASSETS.md](ASSETS.md)
- 다섯 번째 채널 이름은 확정 전까지 `기타 채널`로 표시합니다.

## 파일

`index.html`: 화면 구조 · `style.css`: 반응형 스타일 · `app.js`: 샘플 데이터와 상호작용 · `thumbnails/`: 샘플 사진

기존 Sites 서비스의 저장소 인증 정보와 사이트별 배포 설정은 포함하지 않았습니다.
